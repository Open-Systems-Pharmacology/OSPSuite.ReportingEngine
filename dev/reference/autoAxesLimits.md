# autoAxesLimits

Defines auto axis limits

## Usage

``` r
autoAxesLimits(x, scale = tlf::Scaling$lin)
```

## Arguments

- x:

  Values from which the limits are calculated

- scale:

  Name of the scale of the axis Use helper enum `Scaling` from `tlf`
  package to find scales.

## Value

A list of units for goodness of fit results
