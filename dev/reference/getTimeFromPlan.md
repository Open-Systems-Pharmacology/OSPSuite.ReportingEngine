# getTimeFromPlan

Get endTime value in base unit from configuration plan field

## Usage

``` r
getTimeFromPlan(configurationPlanField, fieldName)
```

## Arguments

- configurationPlanField:

  The configuration plan field listing `endTime` value and unit

- fieldName:

  The name of the field to extract the time from (e.g., "EndTime")

## Value

`endTime` value in base unit
