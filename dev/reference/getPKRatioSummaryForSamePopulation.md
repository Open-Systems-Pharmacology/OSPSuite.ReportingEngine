# getPKRatioSummaryForSamePopulation

Calculate and save summary statistics of ratios of PK parameters if
populations are identical

## Usage

``` r
getPKRatioSummaryForSamePopulation(structureSet, referenceSet)
```

## Arguments

- structureSet:

  A `SimulationStructure` object of the population to compare

- referenceSet:

  A `SimulationStructure` object of the reference population

## Value

A data.frame of the PK Parameter ratios summary statistics
