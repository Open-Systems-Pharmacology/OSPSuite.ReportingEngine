# getAggregateFromStat

Get summary statistics of output values

## Usage

``` r
getAggregateFromStat(statisticId, time, outputValues)
```

## Arguments

- statisticId:

  Statistic Id as defined in `ConfigurationPlan` used for data
  aggregation

- time:

  Time values on which output values are aggregated

- outputValues:

  Output values to be aggregated

## Value

A data.frame of aggregated data to display
