# getAxesProperties

Get identified axes properties from global field `AxesSettings` of
configuration plan or from plot specific field `Axes`. The identified
properties are directly compatible with `tlf` package nomenclature

## Usage

``` r
getAxesProperties(axesSettings)
```

## Arguments

- axesSettings:

  list of axes properties defined in `Axes` field of configuration plan

## Value

A list of properties for axes identified for `x`, `y` and `y2` axes. The
identified properties are directly compatible with `tlf` package
nomenclature
