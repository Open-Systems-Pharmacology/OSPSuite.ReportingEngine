# getObservedDataFromConfigurationPlan

Get selected observed data from a `ConfigurationPlan` object

## Usage

``` r
getObservedDataFromConfigurationPlan(observedDataId, configurationPlan)
```

## Arguments

- observedDataId:

  Identifier of observed data

- configurationPlan:

  A `ConfigurationPlan` object that includes methods to find the data

## Value

list of including data and metaData to perform time profile plot
