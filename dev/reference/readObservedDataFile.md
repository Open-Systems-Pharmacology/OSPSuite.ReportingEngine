# readObservedDataFile

Read observed data file with Nonmem format. Can read csv files as well
as

## Usage

``` r
readObservedDataFile(fileName, header = TRUE, encoding = "UTF-8")
```

## Arguments

- fileName:

  name of file to be read

- header:

  logical indicating if data has a header

- encoding:

  encoding of the file

## Value

data.frame containing observed data
