# getPKRatioSummaryFromAnalyticalSolution

Get PK Ratio Summary from Analytical Solution

## Usage

``` r
getPKRatioSummaryFromAnalyticalSolution(
  pkData,
  referencePKData,
  simulationSetName
)
```

## Arguments

- pkData:

  A data.frame of PK Parameter values for the Population to compare

- referencePKData:

  A data.frame of PK Parameter values for reference Population

- simulationSetName:

  Name of simulation set

## Value

A data.frame of the PK Parameter ratios summary statistics
