# checkPKParameterEndTime

Check consistency of PK Parameter end time

## Usage

``` r
checkPKParameterEndTime(pkParameterName, endTime)
```

## Arguments

- pkParameterName:

  PK Parameter name. See
  [`ospsuite::allPKParameterNames()`](https://www.open-systems-pharmacology.org/OSPSuite-R/reference/allPKParameterNames.html)
  for more details

- endTime:

  Qualification `EndTime` field
