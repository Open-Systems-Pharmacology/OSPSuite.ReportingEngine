# mapStudyDesignSources

mapStudyDesignSources

## Usage

``` r
mapStudyDesignSources(data, population, simulation)
```

## Arguments

- data:

  data.frame read from a study design file

- population:

  `Population` object

- simulation:

  `Simulation` object

## Value

vector of expressions assigning target values Must be the same length as
target values
