# getOutputsFromTimeProfileConfiguration

Get a vector of output paths that are to be used in a time profile plot

## Usage

``` r
getOutputsFromTimeProfileConfiguration(plot)
```

## Arguments

- plot:

  is a descriptor of the plot that is read from the `ConfigurationPlan`
  that is generated by the configuration plan json

## Value

A vector of output paths that are to be used in the time profile plot
descriptor `plot`
