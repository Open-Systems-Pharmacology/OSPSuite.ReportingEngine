# getWorkflowReferencePopulationName

Get `simulationSetName` from the reference `PopulationSimulationSet` of
a `Workflow` object

## Usage

``` r
getWorkflowReferencePopulationName(workflow)
```

## Arguments

- workflow:

  A `PopulationWorkflow` object
