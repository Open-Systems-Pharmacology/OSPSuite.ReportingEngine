# StatisticsTypes

List of available statistic types summarizing data for time profile
plots

- `"2.5th-97.5th Percentiles"` summarizes data using median, 2.5th and
  97.5th percentiles

- `"5th-95th Percentiles"` summarizes data using median, 5th and 95th
  percentiles

- `"10th-90th Percentiles"` summarizes data using median, 10th and 90th
  percentiles

- `"Geometric mean"` summarizes data using geometric mean and mean \*/
  geometric standard deviation

- `"Arithmetic mean"` summarizes data using arithmetic mean and mean +/-
  standard deviation

## Usage

``` r
StatisticsTypes
```

## Format

An object of class `list` of length 5.
