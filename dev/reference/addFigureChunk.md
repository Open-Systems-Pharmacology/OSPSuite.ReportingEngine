# addFigureChunk

Add a figure in a .md document

## Usage

``` r
addFigureChunk(
  fileName,
  figureFileRelativePath,
  figureFileRootDirectory,
  figureCaption = ""
)
```

## Arguments

- fileName:

  name of .md file

- figureFileRelativePath:

  path to figure relative to working directory

- figureFileRootDirectory:

  working directory

- figureCaption:

  caption of figure
