# getMassBalancePlotConfiguration

Get mass balance time profile plot configuration

## Usage

``` r
getMassBalancePlotConfiguration(plotType, data, metaData, settings)
```

## Arguments

- plotType:

  One of the 5 plot types displayed by mass balance task

- data:

  data.frame

- metaData:

  meta data on `data`

- settings:

  User-defined options

## Value

A `tlf` `PlotConfiguration` object
