# getObservedDataFromOutput

Get selected observed data from an Output object

## Usage

``` r
getObservedDataFromOutput(output, data, dataMapping, molWeight, structureSet)
```

## Arguments

- output:

  An `Output` object

- data:

  A data.frame

- dataMapping:

  A list mapping the variable of data

- molWeight:

  Molar weight for unit conversion of dependent variable

- structureSet:

  A `SimulationStructure` object

## Value

list of data and its metaData
