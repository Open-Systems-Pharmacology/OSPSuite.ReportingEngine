# getSensitivityVariableParameterPaths

Get the variable paths for sensitivity analysis settings

## Usage

``` r
getSensitivityVariableParameterPaths(excelFile, sensitivityParametersSheet)
```

## Arguments

- excelFile:

  name of the Excel file from which the R script is created

- sensitivityParametersSheet:

  name of sheet defining the parameters to vary

## Value

Text of vector of paths to vary
