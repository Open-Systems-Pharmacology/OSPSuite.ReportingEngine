# updateVpcPlotColor

Update colors of lines and ranges of VPC plots

## Usage

``` r
updateVpcPlotColor(plotObject, output, referenceSimulationSetName = NULL)
```

## Arguments

- plotObject:

  A ggplot object

- output:

  An `Output` object

- referenceSimulationSetName:

  Display name of reference simulation set

## Value

A ggplot object
