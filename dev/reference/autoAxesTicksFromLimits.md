# autoAxesTicksFromLimits

Defines auto axis ticks from limits for log scale plots. For wide range,
log tick labels display every factor of 10 For small range, log tick
labels displayed at 1,2,5 of every factor of 10

## Usage

``` r
autoAxesTicksFromLimits(limits)
```

## Arguments

- limits:

  Min and max values of axis range

## Value

Numeric values of ticks to display
