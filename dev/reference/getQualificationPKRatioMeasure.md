# getQualificationPKRatioMeasure

Get qualification measure of pk ratio from field `PKRatioPlots` of
configuration plan

## Usage

``` r
getQualificationPKRatioMeasure(pkParameterName, data, metaData)
```

## Arguments

- pkParameterName:

  Name of PK Parameter as defined by users

- data:

  data.frame with PK Ratios

- metaData:

  metaData with units and dimension for labeling the table header

## Value

A data.frame
