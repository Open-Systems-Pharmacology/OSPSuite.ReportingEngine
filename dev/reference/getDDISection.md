# getDDISection

Plot observation vs prediction for DDI qualification workflow

## Usage

``` r
getDDISection(dataframe, metadata, sectionID, idPrefix, captionSuffix = NULL)
```

## Arguments

- dataframe:

  of DDI data for current DDI section

- metadata:

  for DDI plots

- sectionID:

  of report

- idPrefix:

  unique ID to index task results

- captionSuffix:

  to append to qualification plan title

## Value

a `list` of DDI results for the current DDI section
