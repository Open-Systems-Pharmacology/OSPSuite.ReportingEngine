# getWorkflowContent

Creates a character vector to be written in a workflow .R script
defining `Workflow` object

## Usage

``` r
getWorkflowContent(workflowTable, excelFile)
```

## Arguments

- workflowTable:

  Data.frame read from the Excel sheet "Workflow and Tasks"

- excelFile:

  name of the Excel file from which the R script is created

## Value

Character vector defining the `Workflow` object
