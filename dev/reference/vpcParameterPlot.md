# vpcParameterPlot

Plot vpc like plot of yParameter along xParameter

## Usage

``` r
vpcParameterPlot(
  data,
  metaData = NULL,
  plotConfiguration = NULL,
  plotObject = NULL
)
```

## Arguments

- data:

  data.frame

- metaData:

  list of metaData about `data`

- plotConfiguration:

  PlotConfiguration R6 class object

- plotObject:

  ggplot object to which layer is added

## Value

ggplot object
