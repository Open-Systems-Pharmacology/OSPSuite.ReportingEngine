# checkIsSamePopulation

Check if 2 simulation sets use the same population. Same population is
identified as 1- same population file and 2- same study design file (if
defined)

## Usage

``` r
checkIsSamePopulation(simulationSet, referenceSet)
```

## Arguments

- simulationSet:

  A `PopulationSimulationSet` object

- referenceSet:

  A `PopulationSimulationSet` object

## Value

A logical
