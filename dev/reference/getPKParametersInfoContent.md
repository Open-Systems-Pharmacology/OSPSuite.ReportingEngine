# getPKParametersInfoContent

Creates a character vector to be written in a workflow .R script
defining `pkParameters` input of `Output` object.

## Usage

``` r
getPKParametersInfoContent(excelFile, pkParametersSheet)
```

## Arguments

- excelFile:

  name of the Excel file from which the R script is created

- pkParametersSheet:

  name of the Excel sheet that defines the `pkParameters` information

## Value

Character vector defining `pkParameters` input of `Output` object
