# getObservedDemographyFromSimulationSet

getObservedDemographyFromSimulationSet

## Usage

``` r
getObservedDemographyFromSimulationSet(structureSet, demographyPaths, metaData)
```

## Arguments

- structureSet:

  A `SimulationStructure` object

- demographyPaths:

  Names of demography variables to display

- metaData:

  Meta data of demography variables to display

## Value

A data.frame
