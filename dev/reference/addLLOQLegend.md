# addLLOQLegend

Add LLOQ displayed legend to the legend of a `plotObject`

## Usage

``` r
addLLOQLegend(plotObject, captions, prefix = "LLOQ for")
```

## Arguments

- plotObject:

  A ggplot object

- captions:

  Current observed data captions for which lloq legend is needed

- prefix:

  Prefix for legend

## Value

A list of aesthetic values
