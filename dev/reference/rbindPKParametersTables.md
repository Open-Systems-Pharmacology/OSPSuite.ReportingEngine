# rbindPKParametersTables

Concatenate data.frames of PK and Population Parameters across
simulation sets

## Usage

``` r
rbindPKParametersTables(pkParametersTableAcrossPopulations, pkParametersTable)
```

## Arguments

- pkParametersTableAcrossPopulations:

  A data.frame of PK and Population Parameters across simulation sets

- pkParametersTable:

  A data.frame of PK and Population Parameters for a simulation set

## Value

A data.frame of PK and Population Parameters across simulation sets
