# getSmartZoomLimits

Get default axis limits for DDI Ratio plot

## Usage

``` r
getSmartZoomLimits(dataVector, residualsVsObserved = FALSE)
```

## Arguments

- dataVector:

  a numeric vector containing the x or y values of datapoints to be
  plotted

- residualsVsObserved:

  A logical values indicating if DDI Ratios are plotted as residuals vs
  observed

## Value

a list containing the minimum and maximum axes limits
