# getBoxWhiskerPlotConfiguration

Define a `PlotConfiguration` object

## Usage

``` r
getBoxWhiskerPlotConfiguration(
  plotScale = "log",
  colorGrouping = NULL,
  data,
  metaData,
  dataMapping = NULL,
  plotConfiguration = NULL
)
```

## Arguments

- plotScale:

  Scale of Y Axis

- data:

  A data.frame

- metaData:

  dimensions and units in the data.frame

- dataMapping:

  `DataMapping` object

- plotConfiguration:

  A user-defined `PlotConfiguration` object

## Value

A `PlotConfiguration` object
