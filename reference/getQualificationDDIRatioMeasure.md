# getQualificationDDIRatioMeasure

Get qualification measure of DDI ratio from field `DDIRatioPlots` of
configuration plan

## Usage

``` r
getQualificationDDIRatioMeasure(summaryDataFrame, pkParameterName, delta)
```

## Arguments

- summaryDataFrame:

  data.frame with DDI Ratios

- pkParameterName:

  Name of PK Parameter as defined by users

- delta:

  Delta value from Guest et al. formula

## Value

A data.frame
