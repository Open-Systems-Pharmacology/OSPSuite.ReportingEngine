# getQualificationPKRatioTable

Get data of pk ratio from field `PKRatioPlots` of configuration plan

## Usage

``` r
getQualificationPKRatioTable(data, metaData)
```

## Arguments

- data:

  data.frame with PK Ratios

- metaData:

  metaData with units and dimension for labeling the table header

## Value

A data.frame with correct numeric format
