# reSettingsNames

Names of the default/global settings stored in `reEnv`. Can be used with
[`getRESettings()`](https://www.open-systems-pharmacology.org/OSPSuite.ReportingEngine/reference/getRESettings.md)

## Usage

``` r
reSettingsNames
```

## Format

An object of class `list` of length 39.
