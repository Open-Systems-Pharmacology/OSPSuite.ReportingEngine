# getOutputsFromGOFMergedPlotsConfiguration

Get a vector of output paths that are to be used in a GOF merged plot

## Usage

``` r
getOutputsFromGOFMergedPlotsConfiguration(plot)
```

## Arguments

- plot:

  is a descriptor of the plot that is read from the `ConfigurationPlan`
  that is generated by the configuration plan json

## Value

A vector of output paths that are to be used in the GOF merged plot
descriptor `plot`
