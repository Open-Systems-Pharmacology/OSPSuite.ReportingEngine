# getObservedDemographyAcrossPopulations

Get Observed Demography data across populations of simulation sets

## Usage

``` r
getObservedDemographyAcrossPopulations(
  structureSets,
  demographyPaths,
  metaData
)
```

## Arguments

- structureSets:

  List of `SimulationStructure` objects

- demographyPaths:

  Paths of demography variables to display

- metaData:

  List of display names and units of demography variables

## Value

A data.frame
