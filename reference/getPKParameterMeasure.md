# getPKParameterMeasure

Get table summarizing the PK Parameter distribution by population

## Usage

``` r
getPKParameterMeasure(data, dataMapping)
```

## Arguments

- data:

  A data.frame of PK Parameter values across Population Simulation sets

- dataMapping:

  A `BoxWhiskerDataMapping` object

## Value

A data.frame summarizing the PK Parameter distribution by population
