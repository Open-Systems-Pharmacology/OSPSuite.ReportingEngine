# getQualificationPKRatioData

Get data of pk ratio from field `PKRatioPlots` of configuration plan

## Usage

``` r
getQualificationPKRatioData(pkRatioPlan, configurationPlan, settings)
```

## Arguments

- pkRatioPlan:

  List providing the PK ratio mapping from field `PKRatioPlots` of
  configuration plan

- configurationPlan:

  A `ConfigurationPlan` object

- settings:

  settings for the task

## Value

list with `data` and `metaData`
