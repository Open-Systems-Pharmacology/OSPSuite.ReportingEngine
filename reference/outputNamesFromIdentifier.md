# outputNamesFromIdentifier

Get the names of output from simulation set identifier

## Usage

``` r
outputNamesFromIdentifier(outputsId)
```

## Arguments

- outputsId:

  Content translated from cell corresponding to outputs in
  SimulationSets sheet. The `outputsId` are expected as
  `"c(outputName1, outputName2, etc.)"`

## Value

names of Output objects in SimulationSets sheet
