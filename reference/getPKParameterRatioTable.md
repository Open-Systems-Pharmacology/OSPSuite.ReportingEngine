# getPKParameterRatioTable

Get Table of summary statistics of PK parameter ratios across simulation
sets

## Usage

``` r
getPKParameterRatioTable(pkParameter, outputPath, structureSets)
```

## Arguments

- pkParameter:

  PK Parameter name

- outputPath:

  Quantity Path name

- structureSets:

  `SimulationStructure` R6 class object
