# getGuestDeltaFromConfigurationPlan

Get Guest et al. delta values for a DDI Ratio plot from the
configuration plan

## Usage

``` r
getGuestDeltaFromConfigurationPlan(ddiRatioPlan)
```

## Arguments

- ddiRatioPlan:

  Properties defined in `DDIRatioPlots` field of configuration plan

## Value

A named list of Guest et al. values
