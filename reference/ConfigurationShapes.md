# ConfigurationShapes

List mapping configuration plan symbols to tlf shapes. Note that the
names only include lower case as the mapping used in
[`tlfShape()`](https://www.open-systems-pharmacology.org/OSPSuite.ReportingEngine/reference/tlfShape.md)
internally translate configuration plan field with
[`tolower()`](https://rdrr.io/r/base/chartr.html) function.

## Usage

``` r
ConfigurationShapes
```

## Format

An object of class `list` of length 22.
