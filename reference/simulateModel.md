# simulateModel

Simulate model, either for an individual or for a given population.

## Usage

``` r
simulateModel(structureSet, settings = NULL)
```

## Arguments

- structureSet:

  `SimulationStructure` R6 class object contain paths of files to be
  used

- settings:

  list of options to be passed on the function

## Value

Simulation results for individual or population
