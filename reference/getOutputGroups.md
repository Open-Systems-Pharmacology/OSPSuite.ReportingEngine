# getOutputGroups

Group paths with same group IDs and check their units and residuals are
consistent

## Usage

``` r
getOutputGroups(metaDataFrame)
```

## Arguments

- metaDataFrame:

  A data.frame with variables `path`, `dimension`, `unit`, `group`,
  `color`, `fill`

## Value

List of data.frames data.frame with variables `path`, `dimension`,
`unit`, `group`, `color`, `fill`
