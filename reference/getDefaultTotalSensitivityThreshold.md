# getDefaultTotalSensitivityThreshold

return the default totalSensitivityThreshold to be used in a population
sensitivity analysis plot

## Usage

``` r
getDefaultTotalSensitivityThreshold(
  totalSensitivityThreshold = NULL,
  variableParameterPaths = NULL
)
```

## Arguments

- totalSensitivityThreshold:

  cut-off used for plots of the most sensitive parameters

- variableParameterPaths:

  vector of paths of parameters to vary when performing sensitivity
  analysis
