# adjustTitlePage

Adjust Qualification Version Information to be displayed on title page

## Usage

``` r
adjustTitlePage(fileName, qualificationVersionInfo = NULL)
```

## Arguments

- fileName:

  name of .md file to update

- qualificationVersionInfo:

  A `QualificationVersionInfo`object defining Qualification Version
  Information to be displayed on title page
