# plotMeanAbsorption

Plot absorption diagnostics time profile

## Usage

``` r
plotMeanAbsorption(structureSet, settings = NULL)
```

## Arguments

- structureSet:

  `SimulationStructure` R6 class object

- settings:

  Options to be defined (e.g. plotConfigurations list of
  `PlotConfiguration` objects)

## Value

list of `ggplot` objects
