# checkSamePopulationIds

Check if PK Analyses with same population actually use the same
IndividualIds

## Usage

``` r
checkSamePopulationIds(setIds, referenceSetIds, setName, referenceSetName)
```

## Arguments

- setIds:

  A vector of IndividualIds for a simulation set

- referenceSetIds:

  A vector of IndividualIds for the reference simulation set

- setName:

  Name of simulation set for warning message

- referenceSetName:

  Name of the reference simulation set for warning message
