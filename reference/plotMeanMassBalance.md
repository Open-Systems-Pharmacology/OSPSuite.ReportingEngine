# plotMeanMassBalance

Plot mass balance diagnostics time profiles, cumulative time profiles,
normalized time profiles and cumulative normalized time profiles

## Usage

``` r
plotMeanMassBalance(structureSet, settings = NULL)
```

## Arguments

- structureSet:

  `SimulationStructure` R6 class object

- settings:

  Options to be defined (e.g. how to group the plot results, or which
  molecule to exclude)

## Value

list of `ggplot` objects
