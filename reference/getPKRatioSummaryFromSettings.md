# getPKRatioSummaryFromSettings

Get PK Parameter Ratio Measure From Monte Carlo Sampling

## Usage

``` r
getPKRatioSummaryFromSettings(pkData, referencePKData, settings)
```

## Arguments

- pkData:

  A matrix of PK Parameter values for Population to compare

- referencePKData:

  A matrix of PK Parameter values for reference Population

- settings:

  A list of task settings

## Value

A data.frame of the PK Parameter ratios summary statistics
