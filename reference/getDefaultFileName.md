# getDefaultFileName

Add suffix and extension to create a default file name for population
files, results files and PK-analysis files.

## Usage

``` r
getDefaultFileName(..., suffix, extension = "csv", sep = "-")
```

## Arguments

- ...:

  names

- suffix:

  Suffix to be added at the end of the file name

- extension:

  file format. Default is `csv`

- sep:

  separation between names and suffix. Default is `-`

## Value

default filename adding default suffix and file extension
