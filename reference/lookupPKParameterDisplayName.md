# lookupPKParameterDisplayName

lookupPKParameterDisplayName

## Usage

``` r
lookupPKParameterDisplayName(output, pkParameter)
```

## Arguments

- output:

  an Output object

- pkParameter:

  a string with the name of the pkParameter from the population
  sensitivity results index file

## Value

the display name of the input pk parameter or the string pkParameter
itself if no display name found
