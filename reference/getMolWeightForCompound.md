# getMolWeightForCompound

Get molecular weight in base unit for a requested compound in a
simulation

## Usage

``` r
getMolWeightForCompound(compoundName, simulation)
```

## Arguments

- compoundName:

  Name of a compound e.g. "Midazolam"

- simulation:

  A `Simulation` object

## Value

molecular weight in base unit or NA if not found
