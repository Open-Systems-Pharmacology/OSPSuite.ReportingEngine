# getPKRatioForMapping

Get data of pk ratio from field `PKRatios` of configuration plan

## Usage

``` r
getPKRatioForMapping(
  pkRatioMapping,
  pkParameterNames,
  configurationPlan,
  settings
)
```

## Arguments

- pkRatioMapping:

  List providing the PK ratio mapping from field `PKRatios` of
  configuration plan

- pkParameterNames:

  Names of PK Parameters as defined by users

- configurationPlan:

  A `ConfigurationPlan` object

- settings:

  settings for the task

## Value

list with `data` and `metaData`
