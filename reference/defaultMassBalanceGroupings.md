# defaultMassBalanceGrouping

Get mass balance default inclusion/exclusion defined as groupings list
Default groups are

- Plasma

- BloodCells

- Interstitial

- Intracellular

- Endosome

- Gallbladder

- Urine

- Feces

- Rest (includes everything else but Saliva compartments)

## Usage

``` r
defaultMassBalanceGroupings(compoundNames)
```

## Arguments

- compoundNames:

  Names of simulation molecules
