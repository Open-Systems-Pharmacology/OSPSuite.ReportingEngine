# simulateWorkflowModels

Simulate model for a population. Run parallel workflow if numberOfCores
\> 1 AND population size is \>1.

## Usage

``` r
simulateWorkflowModels(structureSets, settings = NULL)
```

## Arguments

- structureSets:

  List of `SimulationStructure` objects contain paths of files to be
  used

- settings:

  list of simulation settings

## Value

Simulation results for individual or population
