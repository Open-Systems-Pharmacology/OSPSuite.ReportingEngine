# formatPKParametersTable

Format data.frame of PK and Population Parameters from a simulation set

## Usage

``` r
formatPKParametersTable(structureSet, pkParametersTable, populationTable)
```

## Arguments

- structureSet:

  A `SimulationStructure` object

- pkParametersTable:

  A data.frame of PK parameters

- populationTable:

  A data.frame of population parameters

## Value

A data.frame and its metaData including the values of PK parameters
across Population Simulation sets
