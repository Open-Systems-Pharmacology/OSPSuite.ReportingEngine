# generateDDIQualificationDDIPlot

Plot observation vs prediction for qualification workflow

## Usage

``` r
generateDDIQualificationDDIPlot(ddiPlotData, delta)
```

## Arguments

- ddiPlotData:

  a list containing the plot data.frame, aesthetics list, axes settings
  and plot settings

- delta:

  Delta value from Guest et al. formula

## Value

ggplot DDI plot object for DDI qualification workflow
