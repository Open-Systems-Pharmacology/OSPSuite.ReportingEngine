# getDemographyAcrossPopulations

Get Demography data across populations of simulation sets

## Usage

``` r
getDemographyAcrossPopulations(structureSets, demographyPaths)
```

## Arguments

- structureSets:

  List of `SimulationStructure` objects

- demographyPaths:

  Paths of demography variables to display

## Value

A list of `data` and its `metaData`
