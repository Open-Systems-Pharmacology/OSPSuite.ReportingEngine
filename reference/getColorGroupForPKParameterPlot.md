# getColorGroupForPKParameterPlot

Map colors to population names

## Usage

``` r
getColorGroupForPKParameterPlot(
  output,
  referenceSetName = NULL,
  simulationSetNames
)
```

## Arguments

- output:

  An `Output` object

- referenceSetName:

  Display name of reference simulation set

- simulationSetNames:

  Display names of simulation sets

## Value

A data.frame mapping colors to names
