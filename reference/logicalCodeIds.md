# logicalCodeIds

Some of the identifiers above need to be treated as logical by
[`getIdentifierInfo()`](https://www.open-systems-pharmacology.org/OSPSuite.ReportingEngine/reference/getIdentifierInfo.md)
while usually input as `"Yes"`/`"No"`

## Usage

``` r
logicalCodeIds
```

## Format

An object of class `character` of length 5.
